# 🧪 Práticas Fundamentais — Semana 03

Esta pasta reúne as práticas desenvolvidas durante a **Semana 03 do curso Python Básico — +IFMG**, integrante da trilha de formação **Python e Big Data — 160 horas**.

A etapa é dedicada ao estudo de **modularização e tratamento de exceções**, com foco na construção de programas mais organizados, reutilizáveis e resistentes a erros.

As práticas acompanham progressivamente os conteúdos estudados nas **páginas 47 a 56** do e-book oficial do curso.

---

## 🎯 Objetivo

O objetivo desta etapa é compreender e aplicar os principais recursos relacionados a:

- tratamento de exceções;
- identificação de erros;
- exceções específicas;
- criação de funções;
- parâmetros;
- argumentos;
- retorno de valores;
- parâmetros opcionais;
- argumentos nomeados;
- recursão;
- módulos;
- importação de funções;
- reutilização de código;
- decomposição de problemas;
- criação de funções auxiliares;
- organização de programas;
- função principal.
