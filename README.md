## 🧮 Fórmulas implementadas

Durante a Semana 01, foram implementadas diferentes fórmulas matemáticas.

### Área do triângulo

```python
area = (base * altura) / 2
```

### Média aritmética

```python
media = (nota1 + nota2) / 2
```

### Celsius para Fahrenheit

```python
fahrenheit = (celsius * 9 / 5) + 32
```

### Fahrenheit para Celsius

```python
celsius = (fahrenheit - 32) / 1.8
```

### Índice de Massa Corporal

```python
imc = peso / (altura ** 2)
```

### Salário por horas trabalhadas

```python
salario = horas_trabalhadas * valor_hora
```

### Consumo médio de combustível

```python
consumo_medio = distancia / combustivel
```

### Valor do desconto

```python
valor_desconto = preco * (percentual_desconto / 100)
```

### Preço final

```python
preco_final = preco - valor_desconto
```

### Reajuste salarial

```python
valor_reajuste = salario * (percentual / 100)
salario_novo = salario + valor_reajuste
```

### Comprimento da circunferência

```python
comprimento = 2 * pi * raio
```

### Área do círculo

```python
area = pi * (raio ** 2)
```

## ⚠️ Erros que geraram aprendizado

Os erros identificados durante o desenvolvimento também fazem parte do processo de aprendizagem.

### Diferença entre `^` e `**`

Código incorreto para potência:

```python
raio ^ 2
```

O operador `^` representa XOR bit a bit.

Código correto:

```python
raio ** 2
```

---

### Sobrescrita da função `print()`

Código incorreto:

```python
print = f"Resultado: {valor}"
```

Código correto:

```python
print(f"Resultado: {valor}")
```

---

### Separador decimal

O Python utiliza ponto como separador decimal:

```text
7.6
```

A entrada com vírgula pode produzir erro ao utilizar `float()`:

```text
7,6
```
