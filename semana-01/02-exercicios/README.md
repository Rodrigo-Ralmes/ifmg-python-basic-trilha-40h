# 🧩 Exercícios — Semana 01

Esta pasta reúne os exercícios desenvolvidos durante a **Semana 01** do curso **Python Básico — +IFMG**.

Os exercícios têm como objetivo aplicar, de forma estruturada, os conceitos estudados durante a semana por meio da resolução de problemas.

---

## 🎯 Objetivo

Consolidar os fundamentos iniciais da linguagem Python por meio de atividades que envolvam:

- interpretação de problemas;
- definição de entradas;
- processamento de dados;
- utilização de operadores;
- armazenamento em variáveis;
- apresentação de resultados.

---

## 🧠 Metodologia

Cada exercício pode ser entendido a partir do seguinte fluxo:

```text
Problema
   ↓
Análise
   ↓
Definição das entradas
   ↓
Processamento
   ↓
Implementação em Python
   ↓

Resultado
