# 🔀 Semana 02 — Controle de Fluxo

Esta pasta reúne todo o conteúdo prático desenvolvido durante a **Semana 02 do curso Python Básico — +IFMG**, integrante da trilha de formação **Python e Big Data — 160 horas**.

A etapa é dedicada ao estudo do **controle do fluxo de execução dos programas**, utilizando estruturas de decisão e estruturas de repetição.

---

## 🎯 Objetivo da semana

O objetivo da Semana 02 é compreender e aplicar estruturas capazes de alterar e controlar o fluxo de execução de programas em Python.

Durante esta etapa, são trabalhados conceitos fundamentais como:

- estruturas condicionais;
- decisão simples;
- decisão composta;
- decisões aninhadas;
- operadores relacionais e lógicos em condições;
- estrutura `if`;
- estrutura `if/else`;
- estrutura `if/elif/else`;
- laço de repetição `while`;
- acumuladores e contadores;
- laço de repetição `for`;
- função `range()`;
- interrupção de laços com `break`;
- continuação de laços com `continue`;
- combinação entre decisões e repetições;
- resolução de problemas utilizando controle de fluxo.
