## 06C — Equação do segundo grau

Esta prática implementa a resolução de uma equação do formato:

```text
Ax² + Bx + C = 0
```

Primeiro calcula-se o discriminante:

```text
Δ = B² - 4AC
```

Em Python:

```python
delta = b ** 2 - 4 * a * c
```

Depois:

```text
Δ < 0  → não existem raízes reais
Δ = 0  → uma raiz real
Δ > 0  → duas raízes reais
```

A raiz quadrada é obtida com:

```python
math.sqrt(delta)
```

### Principais conceitos

- módulo `math`;
- `math.sqrt()`;
- exponenciação;
- cálculo de delta;
- tomada de decisão;
- fórmulas matemáticas.

Arquivo: [`pratica06c_equacao_segundo_grau.py`](pratica06c_equacao_segundo_grau.py)
